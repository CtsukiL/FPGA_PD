## 2. 与 STM32 版的对应关系

| Verilog 模块 | STM32 对应 | 说明 |
|---|---|---|
| `top.v` | `main.c` 的 `main()` | 初始化 + 例化 |
| `clk_tick.v` | `Timer.c` 1ms 中断 + 计次分频 | 1ms / 5ms / 40ms / 50ms |
| `adc_if.v` | `AD.c` + main.c 的 4 点滑动平均 | 3PA1030 16 次平均（比 4 点更强） |
| `encoder_if.v` | `Encoder.c` + `Location += Speed` | 32bit 位置，可标定清零 |
| `key_ctrl.v` | `Key.c` + K1~K4 | 2 个板载键压缩 4 个功能 |
| `pid_angle.v` | `PID.c` 的 `PID_Update(&AnglePID)` | Kp0.3 / Ki0.01 / Kd0.4，±100 |
| `pid_pos.v` | `main.c` 里手写的位置环 | Kp0.4 / Ki0 / Kd4，±100，输出死区 3 |
| `ctrl_fsm.v` | `TIM1_UP_IRQHandler()` | 状态机 + 双环调度 + 串级耦合 |
| `motor_pwm.v` | `Motor.c` + `PWM.c` | 20kHz，死区 5，TB6612 方向 |
| `uart_dbg.v` | `Serial.c`（原版未使用） | 新增：调试上报 |
| `led_ind.v` | `LED.c`（PC13） | 4 个 LED 指示（避开 SSPI 专脚） |

| 电机 PWM 频率 / 死区 | 20kHz / 5 | `motor_pwm.v` |

### 两处与原版不同的地方（有意）

1. **补了"三点角度缓冲区清零"**：STM32 那份 `(2)` 版在状态 24/34 回到状态 1 时没有清 `Angle0/1/2`，这是外层主线已经定位并修掉的「第二次起摆就快速猛动掉下来」的根因。FPGA 版按修好的来做。
2. **位置零点在"起摆完成"这一刻重置**（已与 STM32 版同步）：起摆过程中横杆会被 ±35 推力带着转好几圈，如果沿用标定时的旧零点，入区时位置误差会有几百~上千 count，位置环输出（限幅 ±100）立刻饱和，饱和后变成固定的摆杆倾斜偏置，横杆就会朝一个方向**匀加速转圈**（追不上目标）。
   所以入区时把 `pos`（编码器位置）和 `pos_target`（位置目标）一起归零，位置环误差从 0 开始，横杆稳定停在**起摆完成时那个位置**。
   代价：不再回到标定那一刻的位置。若要恢复"回到初始位置"，做法是入区时把 `pos_target` 限制在当前位置 ±204 count（半圈）以内，别让位置环饱和。

## 3. 接线（逻辑派 G1 排针）

> 排针位号在网表里是 **H5 / H6**，板上丝印可能标 **J5 / J6**，**1 号针方向请以实物丝印为准**（用万用表确认 3.3V / GND 后再插）。

| 信号 | 排针 | FPGA 脚 | 接到哪里 |
|---|---|---|---|
| 编码器 A 相 | H5-1 | K16 | 电机编码器 A |
| 编码器 B 相 | H5-2 | J15 | 电机编码器 B |
| ADC 超量程 OTR | H5-3 | J14 | 3PA1030 板 OTR（不用可悬空） |
| ADC 采样时钟 | H5-4 | J16 | 3PA1030 板 CLK |
| ADC 数据 D0 | H5-5 | F14 | 3PA1030 板 D0 |
| ADC 数据 D1 | H5-6 | F16 | 3PA1030 板 D1 |
| ADC 数据 D2 | H5-7 | J13 | 3PA1030 板 D2 |
| ADC 数据 D3 | H5-8 | H11 | 3PA1030 板 D3 |
| ADC 数据 D4 | H5-9 | E16 | 3PA1030 板 D4 |
| ADC 数据 D5 | H5-10 | F15 | 3PA1030 板 D5 |
| ADC 数据 D6 | H5-11 | C16 | 3PA1030 板 D6 |
| ADC 数据 D7 | H5-12 | D15 | 3PA1030 板 D7 |
| ADC 数据 D8 | H5-13 | D16 | 3PA1030 板 D8 |
| ADC 数据 D9 | H5-14 | E14 | 3PA1030 板 D9 |
| 3.3V | H5-38 | — | 3PA1030 板 3.3V（以及 SV01 电位器激励） |
| GND | H5-37 / H5-39 | — | 公共地 |
| 电机 PWM | H6-31 | N15 | TB6612 PWMA |
| 电机 IN1 | H6-32 | P16 | TB6612 AIN1 |
| 电机 IN2 | H6-33 | P15 | TB6612 AIN2 |

板载（不用接线）：

| 功能 | 脚 | 说明 |
|---|---|---|
| 时钟 | T7 | 板载 50MHz 晶振 |
| 按键 key0 | D11 | 单击 = 启停，长按 1s = 标定 |
| 按键 key1 | F10 | 单击 = +60°，双击 = −60° |
| LED0~LED3 | R9 / R7 / N6 / P7 | 低电平点亮（板载另两个 LED 脚 C10/T10 是 SSPI 专用脚，本工程不用） |
| 串口 TX / RX | F12 / F13 | 板载 USB 串口 |

### 供电（重要）

- G1 只允许 **5V** 输入（Type-C）；**12V 只接 TB6612 的 VM**；**全部共地**；上电顺序先 G1 后 12V。
- **TB6612 的 STBY 必须拉高**，否则电机不动（和 3PA1030 的 OE/STBY 极性相反，别搞混）。
- 3PA1030 板的 **OE、STBY 直接接地**（本工程不输出这两个信号，板上接地即可上电工作）。
- SV01 电位器输出 0~3.3V 必须先分压/缓冲到 **0~2V** 再进 3PA1030（否则超量程，OTR 亮）。

## 4. 按键操作

逻辑派 G1 板载只有 2 个按键，把 STM32 版的 K1~K4 压缩进来：

| 操作 | 等价 STM32 | 效果 |
|---|---|---|
| **key0 单击** | K1 | 停止 ↔ 开始起摆（松手立即响应） |
| **key0 长按 1s** | K4 | 标定平衡点 + 记录横杆初始位置（**只在停止态有效**） |
| **key1 单击** | K2 | 位置目标 +60°（68 count） |
| **key1 双击** | K3 | 位置目标 −60°（68 count） |

注意：
- key1 单击要等 400ms 超时才确认（否则无法区分双击），操作时别连按太快。
- 标定键每次按下都会**覆盖**上一次记录：平衡点角度和初始位置都重新记。
- **K4 是单次采样**（和 STM32 `(2)` 版一致）：按下时把摆杆扶稳在机械竖直、横杆保持不动。

## 5. LED 指示（4 个板载 LED）

| LED | 含义 |
|---|---|
| led[0] (R9) | 运行中常亮（对应 STM32 的 PC13） |
| led[1] (R7) | 平衡（PID，状态 4）常亮；起摆阶段（21~34）慢闪 |
| led[2] (N6) | 完成一次标定后亮 0.5s |
| led[3] (P7) | 心跳（约 1.34s 一周期）；ADC 超量程 OTR 时加快到约 0.34s，兼作告警 |

> G1 板载 LED 有 6 个，但另外两个脚 **C10、T10 是 SSPI 专用引脚**：要当普通 IO 用
> 必须打开 `use_sspi_as_gpio`，代价是**不能再用外部 Flash(MSPI) 配置启动**。
> 为保留上电自启动能力，本工程只用 R9 / R7 / N6 / P7 这四个，把 6 条指示语义压缩进去。
> 如果你更想要 6 个灯：在 GUI 里勾 `Project → Configuration → Place & Route →
> Dual-Purpose Pin → Use SSPI as regular`，再把 `.cst` 里的 C10/T10 加回去。

- 115200-8-N-1，板载 F12(TX) / F13(RX) 接 USB 串口。
- 每 100ms 发一帧，固定 16 字节（小端）：`AA 55 | angle(2) | location(4) | angle_out(2) | pos_out(2) | run_state(1) | center_angle(2) | 5A`

python doc\uart_parse.py COM3 -c     # 输出 CSV（可直接粘进 Excel/画图）

## 7. 上板步骤

1. **接线**（第 3 节），先不接 12V，只上 5V 给 G1。
2. **烧录**：V305 下载器接 G1 的 8P JTAG 口 → Gowin Programmer → 选 `impl\pnr\pendulum_fpga.fs` → **SRAM Program**（掉电丢失，调参阶段用）。
3. **看心跳**：led[3] 约 1.34s 一个周期；串口应该每 100ms 有数据 → 说明 FPGA 在跑。
4. **确认角度**：手拨摆杆，串口 `angle` 应平滑变化；若一直是 0 或满量程，检查 3PA1030 的 CLK/D0~D9 接线和 OE/STBY 接地。
5. **确认编码器**：手转横杆，`location` 应跟着增减（1 圈 ±408）；方向反了就把编码器 A/B 两线对调。
6. **接 12V**（TB6612 VM + STBY 拉高 + 共地），单独测电机：按 key0 起摆，观察电机转，不对就停。
7. **标定**：停止态（key0 停止），把摆杆扶到机械竖直、横杆别动，**长按 key0 一秒**（led[2] 闪一下表示标定完成，串口 `center_angle` 变成当前角度）。
8. **起摆**：key0 单击 → 自动起摆 → 进入平衡；平衡后位置环会把横杆拉回标定时那个位置。
9. **位置控制**：key1 单击 +60°、双击 −60°，看横杆是否平滑移动并停住。

## 10. 已知差异与风险

1. **ADC 量程只有 33%**：自制 3PA1030 板前级按 ±5V 双极性设计（`Vout = 0.2×Vin + 1V`），而 SV01 是 0~3.3V 单极性 → 实际只用 1.0~1.66V，分辨率约 **1°/LSB**，且 OPA842 在 ±3V 下大角度可能饱和。改版建议见 FPGA 交接文档（去偏置 + 换轨到轨运放）。
2. **角度更新率 333Hz**（3ms 平均）：角度环仍是 5ms 一次，环路周期与 STM32 完全一致，但角度比 STM32 的 1ms 采样"旧"一点，超调可能略大。
3. **位置环只有 P+D（Ki=0）**：与 STM32 `(2)` 版一致，横杆最终位置会有小稳态误差；`POS_DEADZONE` 式的小误差不纠正，属预期。
4. **电机死区 5**：位置环输出经角度环 ×0.3 衰减后要超过 5 才推得动电机，所以小偏差横杆不动。
5. **本工程未做仿真 tb**：验证靠命令行综合/布线 + 上板（需要的话可以再补 ModelSim 测试平台）。
6. **未上板验证**：代码只做到"编译通过 + 资源合理"，实际起摆/平衡参数需要上板后按 STM32 那套经验微调（起摆推力、CENTER_RANGE、位置环增益）。
